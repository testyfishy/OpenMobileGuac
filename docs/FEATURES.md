# Features and parity

Status of OpenMobileGuac against other mobile remote-desktop clients. Peer columns compiled
2026-11-18; the OpenMobileGuac column and §1 were reconciled with the code on 2026-11-19.

> **The device checklists have not been run.** The maintainer uses the iOS app daily
> through TestFlight against a real Guacamole server (VNC), and the Android app has not been
> run on a device. Everything marked "Built – untested on device" is implemented and
> unit-tested, and has not been checked item by item on a device. Device
> gates G0 and G1 (`docs/PLAN.md`) are still open; test order: `docs/checklists/README.md`.

Other products' features were taken from their own documentation, store listings and
release notes, linked per cell. "?" means the feature could not be confirmed from a fetched
page. It does not mean the product lacks it. No text, code or assets were copied from other
products.

## 1. OpenMobileGuac feature list

Tags:

- **Built – untested on device**: code and unit tests are in the tree; verified at most in a
  desktop browser (demo server). Not yet tested on a phone or against a real server.
- **Partial**: some of it is in the tree; the row says what is missing.
- **Experimental**: built, but expected to fail with some servers or identity providers.
- **Planned**: has a SPEC requirement, PLAN task or §3 gap; no code yet.
- **Not possible with Guacamole today**: the protocol or server does not support it.

IDs refer to `docs/SPEC.md` §6 (SRV-11, FIL-2, AUD-2 and ADM-1…ADM-6 are in §6.8).

## 4. Deliberate differences

- **No account, no relay, no broker.** The app talks only to servers the user adds (SPEC
  G4, §7 Privacy). It will not add a cloud address book, sync service or NAT-traversal
  relay. Reachability is the user's network or VPN.
- **No telemetry, ads or crash SDKs.** Several peers' store privacy labels list usage or
  diagnostics data. We collect none. Diagnostics (DIAG-1) stay on the device and are shared
  only when the user chooses to.
- **No direct RDP/VNC/SSH.** guacd does the protocol work (SPEC §4). Peers that speak RDP
  directly can offer smart-card redirection, multi-monitor and camera redirection; we get
  only what guacd exposes.
- **Limited server administration (changed 2026-11-20).** This was a v1 non-goal. The owner
  then approved connection and folder management (§1 "Server management", SPEC §6.8
  ADM-1…ADM-6), mainly so quality and bandwidth settings can be changed from the phone.
  Users, user groups, permissions and sharing profiles are still not edited in the app; the
  web client remains the tool for those.
- **No global "ignore TLS errors".** Only a CA the user installed on the device, or per-server
  trust of one pinned certificate after showing its fingerprint (SRV-8, docs/tls.md).
- **TOTP seed storage is opt-in and labelled as weakening 2FA** (SRV-9), unlike a silent
  convenience feature.
- **No code, text or assets from closed-source apps.** PocketGuac and the commercial apps
  are feature references only.
- **Open source and free (GPL-3.0-or-later, with an app-store permission; earlier commits
  Apache-2.0)**, with no paid tier or licence key.
