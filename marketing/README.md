# Marketing assets

Banners, store screenshots and icon proposals for **Open Mobile Guac** (short form **OMG**; repository OpenMobileGuac). The reasoning, copy
and screenshot plan are in [docs/store/marketing-review.md](../docs/store/marketing-review.md).

Everything here is drawn in hand-written SVG (generated by `tools/build-svg.mjs` and `tools/build-icons.mjs`) or is a
real capture of the app's built-in **Demo** (no real server, no personal data). No fonts,
images or artwork were downloaded. Every PNG is opaque 24-bit RGB (no alpha), as Google
Play requires and the App Store accepts.

### The icon in the app

`tools/app-assets.mjs` writes the app's own icon files from the same drawing
(`tools/icon-art.mjs`), each at the exact pixel size of the file it replaces:

- iOS `AppIcon.appiconset/AppIcon-512@2x.png` (opaque RGB, no corners) and the
  `Splash.imageset` images;
- Android `mipmap-*/ic_launcher`, `ic_launcher_round`, `ic_launcher_foreground` (art inside
  the inner 66 %), `ic_launcher_monochrome` (Android 13 themed icon), the adaptive-icon
  XML, `values/ic_launcher_background.xml` (`#44702A`) and every `drawable*/splash.png`;
- web `app/public/favicon.svg`.

Run it after changing `icon-art.mjs`: `node marketing/tools/app-assets.mjs`.

Palette of the icon: gradient `#5f8f2e` → `#2a4d1a` (solid stand-in `#44702a`), screen
`#24401a`, frame `#f3f7e8`, avocado skin `#4f7d24`, flesh `#c9e37a`, pit `#7a4a26`.

### Swapping the icon

Every banner and the privacy cards draw the icon from one file through
`<g id="app-icon"><image href="…/brand/banner-icon.svg"/></g>`. To change it:

- set `BANNER_ICON` at the top of `tools/build-icons.mjs` (now `'icon-3'`) and run
  `node marketing/tools/build-icons.mjs`, **or** replace `brand/banner-icon.svg` with any
  self-contained SVG (no external references; a square viewBox; rounded corners drawn in);
- then re-render: `node marketing/tools/render.mjs`.

### Type

System fonts only, the same stack as the app:
`'Segoe UI', system-ui, -apple-system, 'Helvetica Neue', Roboto, Arial, sans-serif`.
Headlines bold (700) with −1 % tracking, supporting lines regular (400), labels semibold
(600). The PNGs were rendered on Windows, so they use Segoe UI. Rendering on a Mac gives SF
Pro with slightly different widths: check line lengths after re-rendering there.

Headline style: two lines, the last key word in mint (dark) or teal (light).

Name treatment: the icon (the OMG mark) followed by **Open Mobile Guac** in bold. Every
banner and the first screenshot carry the line **"Requires your own Apache Guacamole
server"**, in the banners as a mint badge with an info symbol.

## Re-rendering

Requires Node 22+ and Microsoft Edge (or Chrome; set `EDGE` to its path). No npm packages.

```sh
# 1. real captures (only if the UI changed)
cd app && npx vite --port 5377 --strictPort          # leave running
node marketing/tools/capture.mjs                     # all scenes, or name one: iphone-keys
#    (APP_URL=http://127.0.0.1:<port>/ for another port)

# 2. SVG sources, then PNGs at their exact size
node marketing/tools/build-icons.mjs                # icon, Play icon, alternatives, banner-icon.svg
node marketing/tools/app-assets.mjs                 # the app's icon, splash and favicon files
node marketing/tools/build-svg.mjs
node marketing/tools/render.mjs                      # all, or a filter: render.mjs social
```

`tools/`:

- `cdp.mjs`: a minimal Chrome DevTools Protocol driver (built-in `fetch` and `WebSocket`).
  Each run uses a throwaway browser profile in the system temp folder and deletes it.
- `capture.mjs`: drives the app to each scene (fresh profile per scene, so no session
  carries over) and saves `screenshots/raw/*.jpg`.
- `build-svg.mjs`: palette, mark, drawn phone, copy, and every banner and frame layout.
  Edit captions here.
- `icon-art.mjs`: the chosen icon drawing (shared).
- `build-icons.mjs`: the icon, the Play icon, the alternatives and `brand/banner-icon.svg`.
- `app-assets.mjs`: writes the icon, splash and favicon files into `app/`.
- `render.mjs`: renders each SVG at its `width` × `height`, checks the size and writes an
  opaque RGB PNG next to it (via `png.mjs`, Node's `zlib` only).

Sizes: each PNG is under 1.5 MB; the folder is about 24 MB. If it grows, drop the
`iphone-6.9-landscape` set or lower the raw JPEG quality in `capture.mjs`.
